# 文档目录约定

- 本目录记录 Pico 迁移的计划、资料与证据；索引只保留概况和入口，局部细节由各子目录 `AGENTS.md` 承接。
- 当前实现与验证进度只维护在 `STATUS.md`；`plans/` 维护目标、依赖和验收条件，`device-validation/` 保存每次实验的实际结果。计划、构建或上游结果不能替代本项目运行证据。
- 计划按主题命名，不加日期；调研/决策采用 `YYYY-MM-DD-主题.md`，实验采用 `YYYY-MM-DD-序号-主题/`。既有实验目录不为统一命名而改名。
- 使用相对链接；移动说明时更新所有引用，保留仍被引用的章节锚点。历史实验不因新计划改写。
- 短结论、必要元数据与证据校验值进入 Git；大型产物和私有输入只记录位置与校验值，按忽略规则隔离，不放入文档源。
- 实现、官方资料或验证结论变化时，同步相关索引、状态、计划和 skill；不在多个索引里复制完整内容。
