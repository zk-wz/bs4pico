# 验证记录约定

- 每次实验复制 [_TEMPLATE.md](_TEMPLATE.md) 为独立实验目录中的 `RESULT.md`；成功、失败、部分通过或前提不足均保留。重复实验另建批次，不覆盖原记录或证据。
- 记录设备及系统、源码提交和未提交改动、APK 校验值、组件版本/ABI、设置、步骤、预期与实际结果。性能比较还需同一曲目/回放、渲染配置、刷新率和时长。
- 按实验目标验证启动/架构、真实 Steam 登录及游戏/DLC 授权、双眼显示、追踪/坐标、输入/震动、音画同步、暂停/重定位/待机恢复，再做持续性能比较；未覆盖的项目明确写未测。
- 引用可复现的日志、图像或帧时间数据，区分观察与推断；不能把进程启动、未崩溃或产物存在写成游戏可玩，也不能把模拟器结果升级为 Space Pro 真机结论。
- 大型证据使用新的忽略目录；保留路径、大小及校验值，日志脱敏。已归档实验的本地证据位置与校验索引不因文档整理而改变。
- 本机路径和已验证调用保留在 [环境/模拟器记录](WINDOWS_EMULATOR_VALIDATION.md)，不要复制到本文件；可复用操作入口见 [构建说明](../build/README.md)。
- 新结果归档后更新 [项目状态](../STATUS.md)，本目录 README 只保留实验入口，不另维护状态表。
